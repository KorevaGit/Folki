# Folki v1 — продуктовая и UI-спека

Решения сессий 19–20 октября 2026. Источник правды для работ по v1.

## 1. Онбординг

1. **Привет.** Домик 220 pt (крыши абрикос + ягода) на ~35% высоты. «Привет! Я Folki — твой помощник с деньгами» / «Ты тратишь, я считаю. Каждый день покажу, сколько ещё можно». Кнопка «Начать».
2. **«Как начнёшь?»** Индикатора шагов нет, только «‹». Три карточки по 88 pt:
   - «Начать с нуля»;
   - «Меня пригласили»;
   - «Восстановить из iCloud» («Если Folki уже был на другом iPhone»).

   Тап по карточке выбирает путь и сразу переходит дальше.
3. **Бюджет.** «Сколько денег на жизнь?»:
   - чипсы срока «До зарплаты / Месяц / Неделя», по умолчанию «Месяц»;
   - сумма Rounded 52 и своя клавиатура;
   - живая строка «≈ X ₽ в день · N дней».

   **Пропуска нет**, бюджет обязателен.
4. **«Вот что я умею».** Три строки с мини-анимациями 64 pt:
   - «Ты тратишь — я пересчитываю»;
   - «Общее и личное»;
   - «Раскладываю по конвертам».
5. **«Перейти к Folki».** Покадровый переход 0–1800 мс: кольца заполняются, цифра прокручивается, «Потратить» один раз пульсирует, над ней пузырь «Запиши первую трату — покажу, как поменяется день».

**Путь «Меня пригласили».** Экран-инструкция «Открой ссылку из сообщения» и «Жду приглашение…».
- Приглашение пришло: «Ты в семье «X»» → экран личного бюджета.
- Через 10 с ожидания появляется «Пока начать с личного бюджета».

**Путь «Восстановить».** «Ищу твои данные в iCloud…».
- Нашлись: переход сразу на главный экран, экран функций пропускается.
- Ожидание 20 с, «Подождать ещё» добавляет 30 с. Если данные придут позже: «Вижу старый бюджет. Заменить?».

## 2. Главный экран

**Таббар:** «Бюджет / Конверты». «Сводка» удалена. Аналитика и настройки — иконки в шапке.

**Сверху вниз:**
1. Шапка.
2. Календарь недели. Листается только в пределах периода; будущие дни неактивны.
3. Одна плашка по приоритету: красный конверт > «Период закончился» > жёлтый конверт > «Позови семью» (разово, на 3-й день). Смахнуть можно всё, кроме красной.
4. Кольца 260/22. Если семьи нет — одно кольцо 240/30. Внутри личная цифра 56 и под ней семейная 22.
5. «≈ X ₽/день до даты».
6. Кнопки «− Потратить» и «+ Внести», высота 60.
7. «⌄ Траты за период».

**Тап по кольцу** переключает «день ↔ период». При каждом открытии приложения сброс на «день».

**Обновление:** потянуть кольца вниз, под ними подпись о синхронизации.

**Перерасход:**
- «−320 ₽ сверх дня» красным, дорожка кольца гаснет;
- строка «Завтра ≈ X ₽ в день»;
- хаптик `warning` только при переходе дня в минус.

**Прошлый день:** только просмотр.
- «потрачено во вторник», компактный блок вместо кнопок (полоса категорий + «Больше всего: …»);
- капсула «← Сегодня»;
- задним числом записывать нельзя.

**Конец периода:** период молча продлевается на тот же срок. Остаток и минус переносятся, конверты живут по своим датам. Плашка → шторка «Итоги периода» (только по тапу).

## 3. Потратить / Внести / История

**Потратить** — шторка `.large`:
- бюджет, сумма, строки влияния;
- три чипса + «Ещё». Набор — топ-3 за 30 дней, заранее выбрана категория по времени суток;
- «Записать».

Нет даты, плательщика, описания и выбора источника. После записи шторка закрывается: сначала прокручивается цифра, потом догоняет кольцо, хаптик `saved`. «Ещё» открывает вложенную шторку с сеткой категорий.

**Внести** — одна шторка с переключателем «Личный / Семья»:
- **Личный:** сумма, «В семью 30% · X ₽» (тумблер), ползунок на каждый конверт, итог «на жизнь».
- **Семья:** строки-радио «Из моего личного (вклад) / Общие поступления».

**История** — шторка `.large`:
- переключатель «Все / Личные / Семейные»;
- закреплённые заголовки дней с итогом против плана;
- свои траты правятся и удаляются до конца периода, удаление с тостом «Вернуть»;
- чужие только смотреть: «Маша · 14:20».

**Быстрый вход:** виджеты (экран блокировки и домашний, средний с кнопкой «− Потратить») и App Intent (Action Button, Control Center, Shortcuts). Семейная цифра на виджете с «≈».

## 4. Конверты

- **Только регулярные** (сумма + день). «Цели» и «Учесть в этой сумме» удаляются. Разовые цели появятся позже в разделе «Хотелки».
- **Автораспределение:** при каждом поступлении сначала конверты с ближайшими датами, остаток идёт «на жизнь». Ползунки меняют, сколько положить сейчас, но не размер конверта.
- **Обязательный** конверт должен быть полным к дате. Необязательный можно недозаполнить или переложить сверх.
- **Срочность недостачи:**
  - 8+ дней — серый;
  - 3–7 дней — янтарный;
  - 0–2 дня — красный и один пуш с кнопкой «Переложить».
- **Оплата:** мини-шторка с суммой; разница идёт из «на жизнь» или в неё; вопрос «Сделать новым размером?». При оплате кольцо пустеет, поверх на 0.4 с появляется галочка.
- **Вкладка:** сводка «Отложено X из Y», карточки 84 pt с монохромными иконками (цвет только у статуса), оплаченные внизу.
- **Создание:** 13 шаблонов или свой конверт. DatePicker «Ближайшая оплата», для дней 29–31 берётся последний день короткого месяца.

## 5. Семья и вклады

- **Вход:** плашка на 3-й день или настройки. «Позвать» создаёт семью и открывает свой экран + системный share sheet с готовым текстом.
- **Приглашение принимается всегда.** Пустая своя семья заменяется молча, непустая — после подтверждения.
- **Деньги семьи:** вклады из личного + общие поступления. Период свой, по умолчанию копируется у создателя.
- **Вклад:** дефолт 30%, его меняет любой участник; каждый может переопределить свой процент. Семья видит только суммы вкладов. Ролей нет.
- **Семейные конверты:** если до оплаты ≤7 дней и не хватает, рекомендация вклада растёт на недостачу.

## 6. Аналитика и настройки

**Аналитика** (push из шапки):
1. Темп с графиком факта против ровного темпа.
2. Категории, топ-5. Тап → траты категории за период.
3. Обязательные против желаний.
4. Конверты.
5. Вклады (только семья).

Без 50/30/20 и без «Что изменилось».

**Настройки** — системный `Form` в шторке: Бюджет / Семья / Уведомления / Приложение. Действий с деньгами там нет.

## 7. iCloud и метрики

| Ситуация | Поведение |
| --- | --- |
| iCloud выключен | работает локально, статус в настройках, предупреждение при «Позвать» |
| iCloud переполнен | постоянная плашка |
| Нет сети | ничего не показываем, «последняя синхронизация» в настройках |
| Удалён из семьи | экран-объяснение, личный бюджет на месте |
| Переустановка | путь «Восстановить» |

**Метрики:** TelemetryDeck, 10 событий без сумм и категорий:
`onboarding_step`, `onboarding_path`, `budget_set`, `first_spend`, `spend`, `topup`, `envelope_created`, `family_created`, `family_joined`, `widget_used`.

## 8. UI-основа

| Токен | Значение |
| --- | --- |
| Сетка | 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48; поля 20 (SE/mini 16); карточки 16 / радиус 24; тап от 44; главные кнопки 60 |
| Шрифты | Rounded только для денег: hero 56, ввод 52, цифры в карточках 22. SF Pro: заголовок 34, текст 17, подпись 15, мелкая 13 |
| Цвета | личное #EF9F27; семья **ягодный #D4537E** (тёмная #ED93B1); акцент #0F6E56; янтарный статус #BA7517 на #FAEEDA (тёмная #FAC775 на #412402); красный системный, только цифры и 0–2 дня; фон белый, в тёмной теме чёрный с цветными пятнами |
| Хаптики | selection · key (soft 0.4) · saved (light 0.8) · warning (только переход в минус) · boundary (rigid 0.4) |
| Движение | quick `.snappy(0.25)` · standard `.smooth(0.4)` · ring `.spring(0.9, 0.15)` · hero `.spring(1.2, 0.1)` + каскад 80 мс; Reduce Motion → fade 0.2 |
| Голос | Folki говорит «я», без рода (настоящее время); реплики пользователя безличные; обращение на «ты»; без эмодзи |
| Иконка | домик с двумя крышами (абрикос + ягода) = launch screen = hero онбординга |

**Запуск:** контурный домик 96 pt. Текст «Открываем Folki…» появляется только после 600 мс. Кольца заполняются с нуля только при первом запуске за день.
