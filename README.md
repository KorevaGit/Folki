# Folki

Нативный iPhone-трекер личного и семейного бюджета: сколько осталось сегодня и как покупка повлияет на следующие дни.

17 октября 2026 текущий проект FolkiDuo стал основным **Folki**: [KorevaGit/Folki](https://github.com/KorevaGit/Folki). Прежний семейный трекер сохранён в [Folki-Legacy-20261017](https://github.com/KorevaGit/Folki-Legacy-20261017) и архивирован. Его история и данные iCloud не удалялись. Имена Swift-модулей `FolkiDuoCore` и `FolkiDuoPersistence` оставлены внутренними именами пакетов.

## Состояние

Этапы 0–1 реализованы. Для этапов 2–3 добавлены версии модели Core Data V1/V2, SQLite, private/shared CloudKit stores, CKShare, редактор операций и восстановление удалённых записей. Бюджет переживает перезапуск. Четыре кольца и прогноз строятся из независимых снимков личного и семейного бюджетов, суммы хранятся целыми копейками.

**Проверка обмена на двух физических iPhone с разными Apple ID ещё не пройдена.** Подписанная сборка не доказывает синхронизацию. Режим iCloud — интеграционный прототип; локальный режим доступен отдельно. Личные и семейные накопления работают как отдельные цели с пополнением/возвратом; реальные достижения ещё не подключены.

## Запуск

Mac, Xcode 26+ с iOS Simulator SDK и XcodeGen (`brew install xcodegen`).

```sh
xcodegen generate
open Folki.xcodeproj
```

| Схема | Данные и назначение |
| --- | --- |
| `Folki` · Debug/Release | Постоянный локальный бюджет, без подключения к iCloud |
| `Folki-Demo` · Demo | Отдельное приложение с примерами в памяти, без постоянного хранения |
| `Folki-iCloud` · Cloud | Подписанный интеграционный прототип, private/shared stores и приглашения |

Основной bundle ID: `dev.korevagit.folki`, Demo: `dev.korevagit.folki.demo`. Команда `AKH3FW2JK6` и контейнер `iCloud.dev.korevagit.folki` взяты из существующего профиля владельца; закрытых ключей и профилей в Git нет. Cloud — development, не конфигурация для TestFlight.

Локальный и облачный режимы используют один новый каталог `Application Support/FolkiBudgetV1`. Существующие хранилища прежнего приложения не удаляются и не мигрируются автоматически. Перед первым облачным запуском с прежним контейнером нужен аудит его схемы: [инструкция и протокол двух устройств](docs/ICLOUD-GATE.md).

## Навигация

«Сводка» — общее избранное Folki, «Бюджет» — самостоятельный финансовый раздел с собственной палитрой колец Folki. Заголовок выровнен с кнопками, четыре кольца без стрелок расположены на фоне экрана. Кольца уменьшены до 280 pt, календарь стал компактнее. Под кольцами расположены «Потратить» и «Внести», затем числовые показатели и аналитика дня/недели/месяца. Верхние кнопки открывают аналитику, настройки валюты и лимиты расходов. Приглашение в семью доступно в сводке. Общий календарь сводки и бюджета переключает итоги дня и его записи; дата открывает календарь месяца, «Сегодня» возвращает текущие суммы. История и награды открываются внутри бюджета. Задачи и продуктовая корзина предусмотрены как будущие модули.

## Личные и семейные деньги

У пользователя свой личный бюджет и отдельное семейное пространство. У каждого бюджета свои лимиты, история, резервы и накопления. Плательщик семейной покупки не превращает её во вторую личную трату.

Кольца снаружи внутрь: **личный день → семейный день → личный месяц → семейный месяц**. Они показывают оставшуюся часть соответствующего ориентира/лимита. В центре крупно личный остаток дня, ниже меньшим шрифтом общий. Отсутствующий план обозначен «—».

Личные записи и цели находятся в private store, в отдельном графе без связей с семейным. CKShare создаётся только для семейного корня; сервис запрещает передачу личного корня. Реальную изоляцию на двух Apple ID ещё нужно подтвердить в облачном gate.

Миграция V1→V2 сохраняет прежний бюджет как семейный. Личный создаётся отдельно; история не копируется между бюджетами. Это проверяется на настоящем SQLite старой модели.

## Рабочий цикл

1. Выбрать личный или семейный бюджет. Указать месячный лимит и все деньги этого бюджета, включая накопления; при необходимости выделить защищённый резерв.
2. Под кольцами нажать «Потратить» или «Внести» и выбрать личный либо семейный бюджет. Добавить расход, возврат или поступление: сумма, описание, категория, плательщик и дата.
3. Увидеть остаток дня, месяца и прогноз до сохранения. Поступление увеличивает свободные деньги только при явном включении в план.
4. В истории открыть запись для правки; смахнуть для удаления. В разделе «Удалённые» нажать «Восстановить запись».
5. После смены месяца создать новый план: прежние операции остаются в общей истории и доступны для правки.
6. Создать личную или семейную цель. Пополнение и возврат меняют резерв атомарно с историей накоплений и не считаются повторной тратой.
7. В сводке нажать «Добавить члена семьи». В Cloud открыть «Семья и доступ», подготовить приватное приглашение с правом записи. Принимать приглашение нужно без существующего семейного бюджета; личный бюджет может быть настроен — локальный бюджет автоматически не заменяется.

Полная проверка:

```sh
./scripts/check.sh
```

Swift Testing проверяет расчёты, SQLite после повторного открытия, CRUD, возвраты, доходы, резервы, архивные периоды, независимые записи и защиту от устаревшего редактора, изоляцию двух бюджетов, атомарность накоплений и миграцию V1→V2. Затем собираются Debug, Release, Demo и Cloud без подписи для симулятора.

## Валюта

Настройки бюджета позволяют выбрать валюту отображения для обоих бюджетов на этом устройстве. Доступны RUB, USD, EUR, GBP, CNY, KZT, TRY, AED и JPY. Курсы — из официальной XML-ленты Банка России с видимой датой, кэшем и возможностью ручного ввода. После выбора требуется применение; обновление ленты не меняет применённый курс автоматически. История тоже пересчитывается по выбранному курсу.

Новые суммы можно вводить в выбранной валюте. Исходные записи хранятся в рублях, не перезаписываются при переключении и сохраняют точность при правке неизменённой суммы. Это валюта отображения и ввода, а не мультивалютный банковский учёт.

## Аналитика и лимиты

Ниже числовых показателей колец доступны день/неделя/месяц: расходы, возвраты, чистые расходы, поступления, переводы в резервы, динамика и категории. Переводы в накопления не считаются расходами, будущие и удалённые записи исключены. Неделя начинается с понедельника; прошлые периоды рассчитываются по текущим записям до выбранного дня.

Лимиты расходов — месячные плановые цели отдельно для личного и семейного бюджета. Изменение сохраняется без изменения денег и операций; в месячной аналитике показано, сколько осталось до лимита. Дневной остаток уменьшается от исходного ориентира: 2 000 ₽ − 500 ₽ = 1 500 ₽, а после 2 500 ₽ расходов — −500 ₽ красным.
