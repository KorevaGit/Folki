# Нативный UI-прототип

`FolkiHealthConcept.swift` содержит SwiftUI View и `#Preview`, минимальная версия iOS 26. Имя типа сохранено из раннего концепта Folki; репозиторий и будущий application target — FolkiDuo.

Чтобы посмотреть на устройстве/в Canvas, создать iOS App в Xcode, добавить файл и использовать `FolkiHealthConcept()` как корневой View. Готового application target в этом репозитории пока нет.

В прототипе работают вкладки, скролл, две бюджетные дуги, карточки деталей, форма добавления и прогноз. Цели и награды представлены демонстрационными данными. Траты хранятся в памяти; после пересоздания состояния сбрасываются. iCloud и Core Data не подключены.

Проверка типов с Mac и установленным Xcode/iOS SDK:

```sh
./scripts/check-prototype.sh
```

Проверка типов не проверяет запуск на iPhone, VoiceOver, signing или фактическую доставку через iCloud.
