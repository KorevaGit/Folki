# Приложение FolkiDuo — этапы 0–1

Системные SwiftUI-компоненты iOS 26+: NavigationStack, TabView, ScrollView, List, Form и sheet. Liquid Glass навигации рисует система; карточки данных используют обычный systemGroupedBackground.

## Сборка

```sh
xcodegen generate
open FolkiDuo.xcodeproj
```

Схема `FolkiDuo` использует Debug и начинает с пустого пространства. Форма настройки принимает свободный месячный план и текущий остаток после исключения обязательств. Все записи пока в памяти; приложение прямо сообщает об этом.

Схема `FolkiDuo-Demo` запускает конфигурацию Demo с отдельным bundle ID `dev.korevagit.folkiduo.demo`. Код `App/Demo` целиком закрыт `#if FOLKI_DEMO`. Debug/Release не создают примерные траты, цели или награды. Демо фиксирует 17 октября 2026 и содержит согласованные значения из макета.

## Данные и расчёт

`BudgetSession` — наблюдаемая модель на MainActor. Она собирает HouseholdSnapshot, запрашивает DailyBudgetCalculator и публикует единый DailyBudgetSnapshot. View не считает деньги сама: Double применяется только для длины дуги. Редактор использует PurchaseImpactCalculator; предварительная оценка не создаёт запись. Сохранение сначала проверяет новый снимок, затем меняет состояние атомарно.

Проверка суммы полностью передана Money; автор и плательщик — отдельные идентификаторы. Времена операций — Date, а период определяется часовым поясом пространства. Приложение обновляет снимок при активации и каждую минуту, чтобы не сохранять вчерашний ориентир после полуночи. При завершении периода просит создать новый план; автоматический rollover и сохранение истории — будущий этап хранения.

## Ограничения этой вехи

Нет постоянного хранилища, iCloud, редактирования/удаления реальных записей, датировки через редактор, настройки отдельных резервов и выдачи наград из событий. Создание плана — временная локальная форма, не финальный онбординг. Иконка приложения и локализации для других языков не готовы. String Catalog подключён, базовый язык ru.

Демонстрационные цели/награды не подключены к финансовым записям. В обычной сборке они не показываются как достигнутые. Настоящие достижения и цели реализуются после проверки обмена и хранилища.

Сборки unsigned предназначены для симулятора, не для установки на реальный iPhone. Реальная подпись и iCloud-контейнер не зашиты в проект.
