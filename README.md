# FolkiDuo

Нативный iPhone-трекер общего бюджета для двоих. Главный вопрос — сколько можно потратить сегодня и как покупка повлияет на следующие дни.

## Актуальная концепция

- Прокручиваемая сводка в языке Apple Health / Fitness: системная типографика, понятные карточки, подробности по нажатию.
- Крупные кольца в центре: внешнее — остаток дня, внутреннее — остаток месячного свободного плана.
- Прогноз при добавлении расхода, защищённые обязательные платежи и накопления.
- Общие цели и достижения без соревнования партнёров.
- Нативный Liquid Glass в навигации и контролах; без синего акцента и пастельной эстетики.
- Планируемая синхронизация двух разных Apple ID через CloudKit Sharing.

## Состояние

Готова первая инженерная веха: **собираемое iOS-приложение и отдельное финансовое ядро**. Деньги, периоды, резервы, два кольца и прогноз проверяются 25 тестами. Сводка запущена на iPhone-симуляторе.

Постоянное хранение и iCloud пока не подключены: локальный бюджет сбрасывается после закрытия процесса. Цели и награды остаются демонстрацией только в конфигурации Demo. Это ещё не версия для повседневного учёта.

## Запуск приложения

Нужны Mac, Xcode 26+ с iOS Simulator SDK и XcodeGen (`brew install xcodegen`).

```sh
xcodegen generate
open FolkiDuo.xcodeproj
```

- Схема **FolkiDuo**: обычная пустая сборка; можно задать локальный план и записывать расходы в память.
- Схема **FolkiDuo-Demo**: согласованный пример 17 октября, кольца, цель и примеры наград. Другой bundle ID, поэтому не заменяет обычную сборку.
- Debug и Release не создают примерные траты и не включают код `DemoFixtures`.
- Xcode-проект генерируется из `project.yml` и не хранится в Git. Для запуска на физическом iPhone понадобится команда подписи владельца; симулятор собирается без подписи.

## Структура

```text
App/              Нативное приложение; демо-код отдельно в App/Demo
Core/             Swift Package: деньги, снимки, расчёты и unit-тесты
Prototype/        Исторический SwiftUI-прототип дизайна
design/           Актуальный дизайн и архив исследованных направлений
design/interactive/  Редактируемый HTML-фрагмент и браузерное превью
docs/             План разработки
scripts/          Локальные проверки
```

`CONCEPT.md` и старые материалы в `design/` сохраняют историю обсуждения. Если направления расходятся, приоритет у `docs/DEVELOPMENT-PLAN.md`, `Core/README.md`, `DAILY-BUDGET.md` и последнего обновления `design/HEALTH-NATIVE.md`. Название Folki в ранних материалах и SwiftUI-типе относится к прототипу; этот независимый репозиторий называется FolkiDuo. Текущий статус — [docs/PROGRESS.md](docs/PROGRESS.md).

## Технологии

Swift 6, SwiftUI, iOS 26+. Предлагаемая основа хранения — Core Data + `NSPersistentCloudKitContainer` + `CKShare`; подтвердить на технической проверке с двумя Apple ID до расширения приложения. Свои финансовые кольца рисуются SwiftUI, а не используют Activity Rings или HealthKit.

Банковские интеграции, голосовой ввод, склад продуктов, меню, Android и веб-сервис не входят в первую версию.
