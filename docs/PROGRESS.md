# Ход разработки FolkiDuo

## Веха 1 · 17 октября 2026

Ветка: `codex/foundation-budget-core`. Реализованы этапы 0–1 исходного плана.

### Готово

- Генерируемый Xcode-проект, iOS application target, Swift 6, iOS 26+.
- Независимый Swift Package `FolkiDuoCore`, без UI/базы/облака.
- Money с проверяемой целочисленной арифметикой, строгим локализованным вводом и точным распределением копеек.
- Период и число календарных дней в часовом поясе пространства, включая DST и високосный год.
- Снимки бюджета, операции, защищённые резервы и явное назначение доходов.
- Единый расчёт дневного/месячного остатка и прогноза; предварительная оценка не списывает сумму второй раз.
- Нативная прокручиваемая сводка с крупными кольцами, история, форма локального плана и расхода.
- Отдельные Debug/Release и Demo с разными bundle ID. Цели/награды из макетов доступны только как примеры в Demo.
- String Catalog, скрипты генерации/проверки и GitHub Actions для тестов и unsigned simulator build.

### Проверки

- 25 Swift Testing tests в трёх наборах; параметризованные случаи дополнительно покрывают ввод, распределение денег и календарь.
- Единый `scripts/check.sh`: Core tests + Debug, Release, Demo.
- Локально: Xcode 27.0, iOS Simulator SDK 27.0, deployment target 26.0.
- FolkiDuo Demo установлен и запущен в iPhone 18 Pro Simulator; проверен реальный экран, не сгенерированная иллюстрация.
- Обычная сборка установлена и запущена отдельно; начальное пространство пустое, без подставленных примеров.
- CI добавлен на `macos-26`, результат конкретного прогона смотреть в GitHub Checks pull request.

### Не готово

Постоянное хранение и синхронизация, проверка на двух физических Apple ID, полноценный онбординг, цели, реальные достижения, экспорт, миграции и TestFlight. После завершения процесса локальные записи сбрасываются. Этапы 2–7 не объявляются завершёнными.

### Следующий gate

Core Data + NSPersistentCloudKitContainer + CKShare. Подтвердить создание пространства, приглашение, обмен с двух сторон, перезапуск, офлайн и отзыв доступа на двух физических iPhone. Потребуются реальные team/container settings владельца; значения не угадываются и не коммитятся как секреты.
