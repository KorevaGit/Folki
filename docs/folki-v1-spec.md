# Folki v1 — продуктовая и UI-спека

Решения сессий 19–20 октября 2026. Источник правды для работ по v1.

## 1. Онбординг

1. **Привет.** Домик 220 pt (крыши абрикос + ягода) на ~35% высоты. «Привет! Я Folki — твой помощник с деньгами» / «Ты тратишь, я считаю. Каждый день покажу, сколько ещё можно». Кнопка «Начать».
2. **Личный бюджет.** «Сколько денег на жизнь?», под заголовком «Видно только тебе»:
   - чипсы срока «До зарплаты / Месяц / Неделя», по умолчанию «Месяц»;
   - сумма Rounded 52 и своя клавиатура;
   - живая строка «≈ X ₽ в день · N дней»;
   - справа в шапке «Восстановить из iCloud».

   **Пропуска нет**, бюджет обязателен. После сохранения вернуться на этот шаг нельзя.
3. **«Вместе с близкими».** Пузыри семьи, «Общие траты — вместе. Личные — только твои». Без этого экрана о семейном бюджете можно не узнать:
   - «Создать семью» → «Сколько на общие траты?» («Видно всей семье»), тот же экран суммы;
   - «Меня пригласили» → путь ниже;
   - «Позже» → дальше, семью можно создать с главного экрана.
4. **«Вот что я умею».** Три строки с мини-анимациями 64 pt:
   - «Ты тратишь — я пересчитываю»;
   - «Общее и личное»;
   - «Раскладываю по конвертам».
5. **«Перейти к Folki».** Покадровый переход 0–1800 мс: кольца заполняются, цифра прокручивается, «Потратить» один раз пульсирует, над ней пузырь «Запиши первую трату — покажу, как поменяется день».

**Путь «Меня пригласили».** Экран-инструкция «Открой ссылку из сообщения» и «Жду приглашение…».
- Приглашение пришло: «Ты в семейном бюджете» → «Вот что я умею».
- Через 10 с ожидания появляется «Позже».

**Путь «Восстановить».** «Ищу твои данные в iCloud…».
- Нашлись: переход сразу на главный экран, экран функций пропускается.
- Ожидание 20 с, «Подождать ещё» добавляет 30 с. Если данные придут позже: «Вижу старый бюджет. Заменить?».

## 2. Главный экран

**Таббар:** «Бюджет / Конверты». «Сводка» удалена. Аналитика и настройки — иконки в шапке.

**Сверху вниз:**
1. Шапка.
2. Календарь недели. Листается только в пределах периода; будущие дни неактивны.
3. Одна плашка по приоритету: красный конверт > «Период закончился» > жёлтый конверт > «Позови семью» (разово, на 3-й день). Смахнуть можно всё, кроме красной.
4. Кольца 260/22. Если семьи нет — одно кольцо 240/30. Внутри личная цифра 56 и под ней семейная 22.
5. «≈ X ₽/день до даты».
6. Кнопки «− Потратить» и «+ Внести», высота 60.
7. «⌄ Траты за период».

**Тап по кольцу** переключает «день ↔ период». При каждом открытии приложения сброс на «день».

**Обновление:** потянуть кольца вниз, под ними подпись о синхронизации.

**Перерасход:**
- «−320 ₽ сверх дня» красным, дорожка кольца гаснет;
- строка «Завтра ≈ X ₽ в день»;
- хаптик `warning` только при переходе дня в минус.

**Прошлый день:** только просмотр.
- «потрачено во вторник», компактный блок вместо кнопок (полоса категорий + «Больше всего: …»);
- капсула «← Сегодня»;
- задним числом записывать нельзя.

**Конец периода:** период молча продлевается на тот же срок. Остаток и минус переносятся, конверты живут по своим датам. Плашка → шторка «Итоги периода» (только по тапу).

## 3. Потратить / Внести / История

**Потратить** — шторка `.large`:
- бюджет, сумма, строки влияния;
- три чипса + «Ещё». Набор — топ-3 за 30 дней, заранее выбрана категория по времени суток;
- «Записать».

Нет даты, плательщика, описания и выбора источника. После записи шторка закрывается: сначала прокручивается цифра, потом догоняет кольцо, хаптик `saved`. «Ещё» открывает вложенную шторку с сеткой категорий.

**Внести** — одна шторка с переключателем «Личный / Семья»:
- **Личный:** сумма, «В семью 30% · X ₽» (тумблер), ползунок на каждый конверт, итог «на жизнь».
- **Семья:** строки-радио «Из моего личного (вклад) / Общие поступления».
- Для любого поступления показываются текущий бюджет и прогноз «до → после», затем обязательный шаг проверки распределения. После сохранения — результат с фактическим дневным остатком и списком наполненных конвертов.
- Поступление, наполнение конвертов и обе стороны доли семьи сохраняются одной транзакцией, повтор не дублирует деньги.

**История** — шторка `.large`:
- переключатель «Все / Личные / Семейные»;
- закреплённые заголовки дней с итогом против плана;
- свои траты правятся и удаляются до конца периода, удаление с тостом «Вернуть»;
- чужие только смотреть: «Маша · 14:20».

**Быстрый вход:** виджеты (экран блокировки и домашний, средний с кнопкой «− Потратить») и App Intent (Action Button, Control Center, Shortcuts). Семейная цифра на виджете с «≈».

## 4. Конверты

- **Только регулярные** (сумма + день). «Цели» и «Учесть в этой сумме» удаляются. Разовые цели появятся позже в разделе «Хотелки».
- **Автораспределение:** создание конверта не перемещает деньги. При поступлении сохраняется сумма на текущий день (не меньше действующего дневного ориентира или одного дня из поступления), остальное распределяется пропорционально недостаче конвертов со сроком до конца периода. Остаток идёт «на жизнь». Ползунки позволяют вручную изменить распределение, но не размер конверта.
- **Обязательный** конверт должен быть полным к дате. Необязательный можно недозаполнить или переложить сверх.
- **Срочность недостачи:**
  - 8+ дней — серый;
  - 3–7 дней — янтарный;
  - 0–2 дня — красный и один пуш с кнопкой «Переложить».
- **Оплата:** мини-шторка с суммой; разница идёт из «на жизнь» или в неё; вопрос «Сделать новым размером?». При оплате кольцо пустеет, поверх на 0.4 с появляется галочка.
- **Вкладка:** сводка «Отложено X из Y», карточки 84 pt с монохромными иконками (цвет только у статуса), оплаченные внизу.
- **Создание:** шаблон или свой конверт; выбор дня оплаты. Для дней 29–31 берётся последний день короткого месяца. До сохранения предлагается рекомендованное наполнение из текущего остатка с защитой дневного бюджета. Перенос денег — только по включённому пользователем переключателю, вместе с созданием одной транзакцией.
- **Базовая схема:** необязательный ориентир 50/30/20 (необходимое, желания, резерв). После ввода месячного дохода — редактируемые шаблоны жилья, связи и подушки. Даты и суммы пользователь меняет на фактические; добавление шаблонов не перемещает текущие деньги. Еда и транспорт остаются на жизнь.

### Мастер плана

**Главный принцип: объясняем последствиями, а не текстом.** Каждый ввод сразу показывает, что он меняет: цифрой, анимацией, хаптиком. Если шаг нельзя понять без абзаца пояснений, переделываем шаг, а не дописываем текст.
- Заголовок — короткий вопрос («Сколько приходит?»). Подзаголовков и абзацев нет.
- Главный объяснитель — живая цифра «≈ X ₽ в день». Она видна на каждом шаге и пересчитывается от любого ввода: рост — отскок вверх, падение — мягкий счётчик вниз.
- Сквозная метафора — полоса дохода внизу экрана. Каждый шаг откусывает от неё цветной кусок со своей иконкой. Остаток — «на жизнь».
- Кольца в мастере не используются. Кольца — только остаток трат на период на главном экране.
- Обучение жестом: один раз показываем движение (иконка сама «прыгает» на дату) вместо инструкции.
- Пустое поле показывает призрачный пример суммы, а не подпись «введите…».
- Перебор (сумма больше дохода) — красный кусок полосы, тряска и warning-хаптик, без алерта.

**Шаги** (каждый опирается на предыдущий, отдельной страницы «что будет в плане» нет):
1. **Доход.** Поле суммы и быстрые варианты. Снизу появляется стеклянная панель: оценка «≈ X ₽ / день» и полоса дохода.
2. **Когда приходят.** Сетка 1–28, одно или два числа. Дни цикла подсвечиваются, рядом «10 окт → 9 нояб · 31 дн.».
3. **Обязательные платежи с датами.** Конверты-шаблоны (жильё, коммуналка, связь, подписки, кредит, дети). Тап добавляет карточку: сумма и лента дней оплаты в одной карточке. Каждая сумма откусывает кусок полосы, оценка в день падает.
4. **Копилки.** Те же карточки без даты: пополняются в день зарплаты.
5. **Семья** (если есть) — доля пополнений.
6. **Итог.** Конверты с суммами и крупная оценка в день.

Оценка «в день» = (доход − конверты) / дней в цикле зарплаты. Нельзя отложить больше, чем оставляет один день на жизнь: полоса краснеет, трясётся, кнопка «Дальше» неактивна.

## 5. Семья и вклады

- **Вход:** плашка на 3-й день или настройки. «Позвать» создаёт семью и открывает свой экран + системный share sheet с готовым текстом.
- **Приглашение принимается всегда.** Пустая своя семья заменяется молча, непустая — после подтверждения.
- **Деньги семьи:** вклады из личного + общие поступления. Период свой, по умолчанию копируется у создателя.
- **Вклад:** дефолт 30%, его меняет любой участник; каждый может переопределить свой процент. Семья видит только суммы вкладов. Ролей нет.
- **Семейные конверты:** если до оплаты ≤7 дней и не хватает, рекомендация вклада растёт на недостачу.

## 6. Аналитика и настройки

**Аналитика** (push из шапки):
1. Темп с графиком факта против ровного темпа.
2. Категории, топ-5. Тап → траты категории за период.
3. Обязательные против желаний.
4. Конверты.
5. Вклады (только семья).

Без 50/30/20 и без «Что изменилось».

**Настройки** — системный `Form` в шторке: Бюджет / Семья / Уведомления / Приложение. Действий с деньгами там нет.

## 7. iCloud и метрики

| Ситуация | Поведение |
| --- | --- |
| iCloud выключен | работает локально, статус в настройках, предупреждение при «Позвать» |
| iCloud переполнен | постоянная плашка |
| Нет сети | ничего не показываем, «последняя синхронизация» в настройках |
| Удалён из семьи | экран-объяснение, личный бюджет на месте |
| Переустановка | путь «Восстановить» |

**Метрики:** TelemetryDeck, 10 событий без сумм и категорий:
`onboarding_step`, `onboarding_path`, `budget_set`, `first_spend`, `spend`, `topup`, `envelope_created`, `family_created`, `family_joined`, `widget_used`.

### Визуальный профиль и обновление

- Базовый профиль спрашивает ожидаемый доход за выбранный период; одна кнопка создаёт примерное разбиение. Конверты с выбранными значками анимированно наполняются банкнотами. Слайдеры и числовое редактирование меняют цели, показывая остаток на период и на день. Профиль сохраняется отдельно для личного и семейного бюджета и повторно открывается из «Плана»; сохранение не перемещает текущие деньги.
- Переключение вкладок — короткий направленный переход с сохранением навигации каждой вкладки; Reduce Motion убирает перемещение.
- Pull-to-refresh рисует только дугу внутри колец. Системный спиннер и подпись статуса не выводятся.
- Широкий виджет показывает личные и семейные дневные кольца за неделю; сумма семьи — ягодная в обеих темах, в том числе у настроенного бюджета с нулевым остатком.

### Текущие деньги после настройки плана

- Ожидаемый доход задаёт прогноз, а «На повседневное» показывает фактический свободный остаток без денег в конвертах. Остаток виден под кольцом и во вкладке «План».
- После сохранения или перенастройки плана при положительном остатке открывается предложение распределить имеющиеся деньги. Можно изменить суммы либо закрыть предложение; деньги перемещаются только после подтверждения.
- Распределение показывает конверты, остаток на повседневное и дневной бюджет до/после. Все перемещения сохраняются одной операцией без повторного поступления.
- При наличии незаполненных обязательных конвертов и свободных денег главный экран предлагает распределение. Рядом с текущим дневным ориентиром выводится прогноз «По плану» из ожидаемого дохода за вычетом месячных целей конвертов.
- Сброс личного плана возвращает накопленные в его конвертах деньги на повседневное. Ошибка закрытия конверта не скрывается, сброс можно повторить.
- Конверты содержат реальные отложенные деньги, а категории повседневных трат собирают статистику расходов без отдельного баланса и пополнений.

### Источники расходов: конверты и повседневное

- У платежного конверта есть ожидаемая сумма и дата, без обязательного минимума. Ожидаемая сумма используется для прогнозов и предложений распределения; фактический платёж может быть больше или меньше. Признак «Обязательный» задаёт приоритет платежа.
- Во вкладке «План» отдельно показаны «Конверты с деньгами» и «Повседневные траты». Категории вроде продуктов и кафе не требуют пополнения, лимиты для них не обязательны.
- В «Потратить» источник выбирается явно. По умолчанию это повседневный бюджет; выбор категории не выбирает конверт автоматически. Можно выбрать конкретный конверт, в том числе из нескольких с одинаковой категорией.
- Расход из конверта уменьшает его баланс. Если остатка не хватает, интерфейс показывает доплату из повседневного бюджета. Повседневный расход с той же категорией не затрагивает конверты.
- Аналитика за неделю и период показывает общий расход и раздельные суммы «Из конвертов» / «Повседневные», а также отдельную разбивку категорий для каждого источника. Возвраты уменьшают расходы своего источника; пополнения и освобождение конвертов не считаются расходами. Доплата сверх баланса конверта относится к повседневным деньгам.
